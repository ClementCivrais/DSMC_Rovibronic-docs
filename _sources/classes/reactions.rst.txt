Reaction classes
================

Source: ``src/lagrangian/DSMC/reactions/derived/``.

The derived reaction classes are organised **by chemistry model**:
each top-level sub-directory is a model the user can choose from,
and within it the individual reactive channels are implemented::

    reactions/derived/
        QK/     quantum-kinetic reactions: clean per-type dissociationQK,
                ionisationQK (+ recombination via detailed balance), plus the
                legacy combined classes (dissociationIonisation*,
                chargeExchange, associative ionisation, ...)
        TCE/    total-collision-energy reactions (dissociationTCE,
                exchangeTCE, ionisationTCE, recombinationTCE)
        Bias/   Gimelshein-Wysong bias reactions (dissociationBias, ...)

Following the PICLas reference taxonomy, every reaction reduces to one of
four types -- dissociation (D), exchange (E), ionisation (I), recombination
(R) -- handled by a chosen model.  The model x type coverage is:

.. list-table::
   :header-rows: 1
   :widths: 20 20 20 20 20

   * - Model
     - Dissociation
     - Exchange
     - Ionisation
     - Recombination
   * - TCE
     - ``dissociationTCE``
     - ``exchangeTCE``
     - ``ionisationTCE``
     - ``recombinationTCE``
   * - QK
     - ``dissociationQK``
     - (PICLas: n/a)
     - ``ionisationQK``
     - ``recombination`` (detailed balance)

This matches PICLas, where QK is a deterministic threshold model defined only
for dissociation and ionisation (QK recombination is the detailed-balance
backward of a QK dissociation/ionisation), while TCE (Arrhenius) covers all
four types.  All classes use the rovibronic (n,v,J) state-resolved energies.

In addition to the four base types, the **charged-species and associative**
channels are provided for both the TCE and Bias models, reusing the
base-class ``chargeExchangePQ`` and ``associativeIonisation`` primitives:

.. list-table::
   :header-rows: 1
   :widths: 30 35 35

   * - Channel
     - TCE
     - Bias
   * - Charge exchange (A+ + B -> A + B+)
     - ``chargeExchangeTCE``
     - ``chargeExchangeBias``
   * - Associative ionisation (A + B -> AB+ + e-)
     - ``associativeIonisationTCE``
     - ``associativeIonisationBias``
   * - Reverse assoc. ion. (AB+ + e- -> A + B)
     - ``reverseAssociativeIonisationTCE``
     - ``reverseAssociativeIonisationBias``
   * - Exchange / Impact ionisation
     - ``exchangeTCE`` / ``ionisationTCE``
     - ``exchangeBias`` / ``ionisationBias``

Impact ionisation (``ionisationTCE``/``ionisationQK``/``ionisationBias``) is
generic in the collision partner, so it covers electron-impact, atom-atom,
and atom-ion ionisation by choosing the partner species.  The Bias
vibrational-favoring factor is physically active only when a vibrating
molecular reactant is present; for purely atomic/electron reactants it
degenerates gracefully (see ``biasCommon.H``).

The model is selected per reaction through the ``reactionModel``
key in ``system/chemReactDict`` (the run-time type name), so the
directory grouping is organisational; new channels are added under
the relevant model directory. Every reaction class plugs into the
common base that hands it the pooled collision energy
:math:`E_c`, the reactant states, and the RNG; the class then
computes the reaction probability, decides whether the reaction
fires, and —  if it does —  samples the product states through the
Larsen-Borgnakke machinery of :doc:`collision_models`.

A central design choice of the rovibronic extension is that **the
heats of reaction are read from the spectroscopic database**, not
from user-supplied dictionary entries. The theoretical basis is
given in :doc:`../theory/chemistry`; the present page documents
the implemented classes one by one.

.. warning::

   **Charged-species reaction classes are work in progress.** The
   classes flagged as *WIP* below have been ported into the
   rovibronic framework but have not yet been reworked, verified,
   or validated end-to-end. Cases that enable
   ``chargedParticles = true`` in ``constant/dsmcProperties``
   exercise these classes and should be regarded as exploratory
   until the corresponding entries below are updated.

Neutral-chemistry classes (validated)
-------------------------------------

``dissociationQK``
``````````````````

PICLas-style Quantum-Kinetic dissociation,
:math:`\mathrm{AB} + \mathrm{M} \to \mathrm{A} + \mathrm{B} +
\mathrm{M}`. Parameter-free deterministic threshold: dissociates
when :math:`E_c = E_{\mathrm{trans}} + E_{\mathrm{int}}(\mathrm{AB})`
exceeds the state-resolved dissociation energy
:math:`D_0 - E(n,v,J)`. No Arrhenius input.

``ionisationQK``
````````````````

PICLas-style Quantum-Kinetic impact ionisation,
:math:`\mathrm{A} + \mathrm{B} \to \mathrm{A}^{+} + e^{-} +
\mathrm{B}`. Deterministic threshold: ionises when
:math:`E_{\mathrm{trans}} + E_{\mathrm{int}}(\mathrm{A})` exceeds
the ionisation potential. No Arrhenius input; products via
``ionisePQ``.

``dissociationIonisationTypeISameSpecies``
``````````````````````````````````````````

Same-species dissociation (e.g.
:math:`\mathrm{N_2} + \mathrm{N_2} \to \mathrm{N} + \mathrm{N} +
\mathrm{N_2}`). The dissociating parcel is the first of the
identical reactants; the second acts as the collision partner
and is unchanged.

``dissociationIonisationTypeIDissimilarSpecies``
````````````````````````````````````````````````

Dissimilar-species dissociation (e.g.
:math:`\mathrm{N_2} + \mathrm{O} \to \mathrm{N} + \mathrm{N} +
\mathrm{O}`). The dissociating reactant is identified by type-ID
at run-time.

``dissociationTCE``
```````````````````

Bird Total-Collision-Energy dissociation,
:math:`\mathrm{AB} + \mathrm{M} \to \mathrm{A} + \mathrm{B} +
\mathrm{M}`. The per-collision probability is built from a
user-supplied Arrhenius triple (``preExponentialFactor``,
``temperatureExponent``, ``activationTemperature`` in K) so that
the equilibrium rate reproduces :math:`k(T)` exactly; see
:doc:`../theory/chemistry`. ``zetaBar`` optionally overrides the
computed average internal degrees of freedom.

``exchangeTCE``
```````````````

TCE atom-exchange, :math:`\mathrm{AB} + \mathrm{C} \to
\mathrm{AC} + \mathrm{B}`. Same Arrhenius-derived per-collision
probability as ``dissociationTCE`` (shared ``tceCommon.H`` helper);
products formed via the base ``exchangePQ`` primitive with the heat
of reaction :math:`D_0(\mathrm{AC}) - D_0(\mathrm{AB})` read from
the database.

``ionisationTCE``
`````````````````

TCE impact ionisation, :math:`\mathrm{A} + \mathrm{B} \to
\mathrm{A}^{+} + e^{-} + \mathrm{B}`. Arrhenius-derived probability;
the ion and electron are produced by the base ``ionisePQ``
primitive, which conserves energy using the state-resolved
ionisation threshold.

``recombinationTCE``
````````````````````

TCE three-body recombination, :math:`\mathrm{A} + \mathrm{B} +
\mathrm{M} \to \mathrm{AB} + \mathrm{M}`, following the PICLas
direct route: the per-collision probability of the A-B pair carries
the local third-body number density,
:math:`P = C_1\, n_M\, E_c^{\,\eta-1+\omega}`, with the recoil
absorbed by a third-body parcel (base ``recombinePQ``). The
three-body Arrhenius prefactor ``preExponentialFactor`` is in
:math:`\mathrm{m^6/s}`.

``dissociationBias``
````````````````````

Gimelshein-Wysong vibrationally-favored Bias dissociation,
:math:`\mathrm{AB} + \mathrm{M} \to \mathrm{A} + \mathrm{B} +
\mathrm{M}`. The probability adds an explicit vibrational-favoring
factor :math:`\exp[\lambda(E_v/E_d - 1)]` to bias dissociation
toward high vibrational states; the calibration constant
``aCoeff`` and favoring exponent ``lambda`` are read from the
dictionary, while :math:`E_v, E_r, E_d` come from the rovibronic
database. See :doc:`../theory/chemistry`.

``dissociationIonisationExchange``
``````````````````````````````````

Atom-exchange (Zeldovich-type) reactions,
:math:`\mathrm{AB} + \mathrm{C} \to \mathrm{AC} + \mathrm{B}`.
The heat of reaction is computed from the database as
:math:`\Delta H = D_0(\mathrm{AC}) - D_0(\mathrm{AB})`, without
user input. Product sampling follows the two-stage LB procedure
described in :doc:`../theory/chemistry`.

``recombination``
`````````````````

Three-body recombination,
:math:`\mathrm{A} + \mathrm{B} + \mathrm{M} \to \mathrm{AB} +
\mathrm{M}`. The rate is derived parameter-free from the
corresponding dissociation rate through the equilibrium constant
:math:`K_{\mathrm{eq}}(T)`; see :doc:`../theory/chemistry`.

Polyatomic-chemistry classes (validated)
----------------------------------------

These classes extend TCE and QK chemistry to **polyatomic
reactants and products**, summing the collision energy over all
oscillators of the molecule. The governing physics is documented in
:doc:`../theory/chemistry`.

``polyDissociationTCE``
```````````````````````

TCE dissociation of a polyatomic,
:math:`\mathrm{AB}_2 + \mathrm{M} \to \mathrm{AB} + \mathrm{B} +
\mathrm{M}`. Arrhenius-calibrated forward probability
(``preExponentialFactor``, ``bf``, ``activationTemperature``,
``formationEnergy``), reducing to the verified diatomic TCE in the
single-oscillator limit. ``productMolecule`` and ``productAtom``
name the fragments; ``xiCMode`` selects the internal-DOF accounting
(``cellThermal`` default, ``perCollision``, ``shape``).

``polyDissociationQK``
``````````````````````

Parameter-free QK dissociation of a polyatomic: dissociates when
:math:`E_{\mathrm{rel}} + E_{\mathrm{int}}` exceeds the bond energy
:math:`D_0`, with :math:`E_{\mathrm{int}}` summed over the full
internal manifold. Only ``formationEnergy`` (= :math:`-D_0`) is
required.

``polyExchangeTCE``
```````````````````

TCE atom exchange with a polyatomic reactant and/or product,
:math:`\mathrm{A} + \mathrm{BC} \leftrightarrow \mathrm{AB} +
\mathrm{C}` (e.g. :math:`\mathrm{CO}_2 + \mathrm{O}
\leftrightarrow \mathrm{CO} + \mathrm{O}_2`). The ``rateMethod``
key selects ``arrhenius`` (forward) or ``detailedBalance`` (reverse,
:math:`k_b = k_f/K_{\mathrm{eq}}`); ``productsOfExchangeReaction``
names the two products.

``polyRecombinationTCE`` / ``polyRecombinationQK``
``````````````````````````````````````````````````

Detailed-balance partners of the two dissociation classes,
:math:`\mathrm{AB} + \mathrm{B} + \mathrm{M} \to \mathrm{AB}_2 +
\mathrm{M}`. The backward rate is built from the partition-function
equilibrium constant with the exact barrierless prefactor described
in :doc:`../theory/chemistry`; ``reactantAtomsToRecombine``,
``productOfRecombination`` and ``thirdBody`` configure the channel.

``moleculeAtomDissociationIonisation``
``````````````````````````````````````

Dissociation of a molecule by an atomic partner, with the
optional ionisation branch when the collision energy exceeds the
state-dependent ionisation threshold. The dissociation branch
(neutral products) is part of the validated neutral-chemistry
block; the ionisation branch reuses the charged-species
infrastructure flagged below.

Charged-species reaction classes (WIP)
--------------------------------------

.. warning::
   Each class in this section is flagged as **work in progress**.
   The notes below describe the intended physics; the
   implementation is in place but has not been end-to-end
   verified and validated in the rovibronic context.

``atomAtomIonisationSameSpecies``
`````````````````````````````````

Same-species atom-atom ionisation, e.g.
:math:`\mathrm{N} + \mathrm{N} \to \mathrm{N}_2^{+} + e^{-}` or
direct
:math:`\mathrm{N} + \mathrm{N} \to \mathrm{N} + \mathrm{N}^{+}
+ e^{-}`. The implemented form assumes the ionisation potential
is state-dependent through the electronic level of the reactants.

``atomAtomIonisationDissimilarSpecies``
```````````````````````````````````````

Dissimilar-species atom-atom ionisation (e.g.
:math:`\mathrm{N} + \mathrm{O} \to \mathrm{NO}^{+} + e^{-}`).

``atomElectronIonisation``
``````````````````````````

Electron-impact ionisation of an atom,
:math:`\mathrm{A} + e^{-} \to \mathrm{A}^{+} + 2\, e^{-}`.

``atomIonIonisation``
`````````````````````

Ion-atom ionisation,
:math:`\mathrm{A} + \mathrm{B}^{+} \to \mathrm{A}^{+} +
\mathrm{B}^{+} + e^{-}`.

``chargeExchange``
``````````````````

Charge-exchange reactions,
:math:`\mathrm{A}^{+} + \mathrm{B} \to \mathrm{A} +
\mathrm{B}^{+}`. The heat of reaction is computed automatically
as :math:`\Delta H_{\mathrm{cx}} = \mathrm{IP}(\mathrm{A})
- \mathrm{IP}(\mathrm{B})`.

``forwardAssociativeIonisation``
````````````````````````````````

Associative ionisation in the forward sense,
:math:`\mathrm{A} + \mathrm{B} \to \mathrm{AB}^{\star} \to
\mathrm{AB}^{+} + e^{-}`. Implemented as the two-step
intermediate-formation / ionisation-test algorithm documented in
:doc:`../theory/chemistry`.

``forwardAssociativeIonisationDissimilarSpecies``
`````````````````````````````````````````````````

The dissimilar-reactant variant of the above.

``reverseAssociativeIonisation``
````````````````````````````````

The reverse branch,
:math:`\mathrm{AB}^{+} + e^{-} \to \mathrm{A} + \mathrm{B}`.

``moleculeElectronDissociationIonisation``
``````````````````````````````````````````

Electron-impact dissociation of a molecule, with optional
ionisation of the products.

``moleculeIonDissociationIonisation``
`````````````````````````````````````

Ion-impact dissociation of a molecule, with optional ionisation.

Common reaction-dictionary conventions
--------------------------------------

A reaction is registered in ``system/chemReactDict`` by a named
block. The core entries are:

.. code-block:: cpp

   reactionName
   {
       reactionModel      <class>;     // one of the above
       reactants          (<A> <B>);
       // products, depending on class, e.g.:
       productsOfDissociationReaction (<P> <Q> <R>);
       productsOfExchangeReaction     (<P> <Q>);
       productOfRecombination         <AB>;
       reactantAtomsToRecombine       (<A> <B>);
       // QK rate law parameters:
       aCoeff             <scalar>;
       bCoeff             <scalar>;
       // ionisation heat (only ionisation channels require this):
       heatOfReactionIonisation  <Kelvin>;
   }

Dissociation and exchange heats are *not* read from the dictionary
—  they are computed from the database at initialisation and
printed to the terminal for verification. Legacy ``heatOfReactionExch``
entries are silently ignored.

Reporting and diagnostics
-------------------------

If ``printReactionsToTerminal`` is enabled in ``dsmcProperties``
(legacy key, kept for compatibility), the solver prints the
running count of each reaction channel at every output step.
This is the most direct way to confirm that a given channel is
firing at all; a persistently zero count often reveals either a
missing ``reactants`` entry or an unreachable activation energy.
