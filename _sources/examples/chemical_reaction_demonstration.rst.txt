Chemical-reaction demonstration (WIP)
=====================================

Directory: ``tutorials/chemicalReactionDemonstration/``.

.. warning::

   The case carries the singly-ionised species and the electron in
   ``typeIdList``, but the ionisation branches of the
   ``dissociationIonisationTypeI*`` classes are not active in the
   current solver, so no charged species are produced. Every
   charged-species reaction class is **work in progress** (see
   :doc:`../classes/reactions`); the tutorial exercises the neutral
   chemistry with the charged species present in the mixture.

A closed-box air-plasma reactor covering the full
N\ :sub:`2` / O\ :sub:`2` / NO / N / O neutral chemistry plus
the associated singly-ionised species and electrons. The case
registers the dissociation, exchange, and recombination reactions
of the neutral block with the charged species present in the
mixture, and is designed as an end-to-end smoke test of every
``reactionModel`` in the ``chemReactDict``.

Theoretical basis
-----------------

The case exercises two complementary reaction blocks:

* **Neutral chemistry** — dissociation via the Quantum-Kinetic
  (QK) model, Zeldovich exchange with automatic heat-of-reaction
  computation, and three-body recombination from detailed
  balance. Full derivations are given in
  :doc:`../theory/chemistry`; the post-reaction Larsen-Borgnakke
  redistribution is described in :doc:`../theory/larsen_borgnakke`.
  This block is validated and produces quantitatively meaningful
  results.
* **Charged-species chemistry** — electron-impact ionisation,
  atom-atom / atom-ion / molecule-ion ionisation channels,
  charge exchange, and associative ionisation (forward and
  reverse). The underlying physics —  state-dependent ionisation
  threshold :math:`E_{\mathrm{ion}}(n,v,J) = E_{\mathrm{IP}}
  - E(n,v,J)`, the **ambipolar-diffusion** treatment of
  electrons (created at their parent ion's position), and the
  **electron sub-time-stepping** through
  ``noTimeCounterSubCycled`` —  is documented in
  :doc:`../theory/chemistry_charged`. Every class in this block
  is flagged as *work in progress* on
  :doc:`../classes/reactions`; the code paths are in place but
  have not been end-to-end verified, and none of these classes
  is registered in the tutorial's ``chemReactDict``.

The case therefore serves as a gating test for changes to any of
the neutral reaction classes in a mixture that also carries the
charged species.

Species
-------

.. code-block:: text

   typeIdList                                  (N2 O2 NO N O N2+ O2+ NO+ N+ O+ E-);

Registered reactions
--------------------

The neutral block in ``system/chemReactDict``, with
``allowSplitting yes`` so that the composition evolves:

* ``O2 + O2 → O + O + O2``
* ``N2 + N2 → N + N + N2``
* ``N2 + O → NO + N`` (Zeldovich exchange, with its
  ``N2 + O`` dissociation channel)
* ``O + O + M → O2 + M`` (recombination)
* ``N + N + M → N2 + M`` (recombination)

Every heat of reaction is computed from the species database. The
Zeldovich exchange is endothermic in this direction and is
therefore declared with ``detailedBalanceExchange``:

.. code-block:: cpp

   N2_O_NO_N_exchange
   {
       reactionModel         detailedBalanceExchange;
       dsmcReactionProperties
       {
           reaction                        N2_O_NO_N_exchange;
           reactants                       (N2 O);
           productsOfExchangeReaction      (NO N);
           productsOfDissociatedMolecule   (N N);
           allowSplitting                  yes;
           writeRatesToTerminal            yes;
       }
   }

Only the ``O2 + O2`` and ``N2 + N2`` dissociations are declared, so
the recombinations with the other third bodies have no reverse
reaction in the simulation; the solver prints a warning for each
of them at start-up.

The ``dissociationIonisationTypeI*`` entries keep their
``productsOfIonisedMolecule`` (a required entry of the class), but
their ionisation branches do not fire.

Validation goals
----------------

#. **Element conservation.** The case must conserve the total
   number density of N atoms and O atoms to within statistical
   noise — the same check as for
   :doc:`isothermal_reactive_heatbath`.
#. **No charged species.** With the ionisation branches
   inactive, the ion and electron populations must stay at zero.
#. **No NaN / no unphysical drift.** The macroscopic fields
   must remain finite throughout the run.

Running
-------

.. code-block:: bash

   cd tutorials/chemicalReactionDemonstration
   blockMesh
   dsmcInitialise
   dsmcFoam

Expected behaviour
------------------

The case should behave like the :doc:`isothermal_reactive_heatbath`
with a richer species list and without the temperature controller;
element conservation (:math:`\sum n_\mathrm{N}`,
:math:`\sum n_\mathrm{O}`) should hold within statistical noise.

A quantitative regression target for the charged phase will be
added once the charged-species classes have been reworked and
validated.
