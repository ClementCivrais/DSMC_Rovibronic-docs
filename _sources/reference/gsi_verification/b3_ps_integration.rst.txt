B3: pure-surface integration
============================

**Verified:** the time integration of the pure-surface (PS)
reactions (desorption DS, Langmuir-Hinshelwood LH2 and LH4,
sublimation SB) with the three integrators of ``psIntegrator``
(``exponential``, ``timeCounter``, ``stochastic``), and the
translation of the legacy coverage-wall keywords into a built-in
mechanism, after which the legacy code path was deleted.
**Against:** SPARTA PS examples one-to-one, closed-form solutions,
an independent Monte Carlo of each discrete algorithm, the published
checks of SG25 [SG25_gsi]_, and the former coverage-wall
verification.

Integrators
-----------

* ``exponential`` (default): the extents :math:`X_r` (real events on
  the element) over :math:`h = n_{sync}\Delta t` are
  :math:`X = h\,\varphi_1(hM)\,R(\theta_0)`, with the Jacobian
  :math:`M` written analytically in every PS class and the matrix
  function from a Padé(6,6) exponential of the augmented matrix.
  Exact for linear networks at any :math:`k\,\Delta t`; non-linear
  reactions take adaptive sub-steps. Per-element carries of every gas
  product emit whole parcels (no rounding draw).
* ``timeCounter``: SPARTA's ``PS_react`` (multiple time counters,
  SG25 Algorithm 2 with SPARTA's floor).
* ``stochastic``: the exact stochastic simulation algorithm (SG25
  Algorithm 3 with the waiting time drawn before the event).

The time counter is SPARTA one-to-one, serial, decomposed and
restarted. The exponential integrator agrees on every channel fixed
by the mass balance, but its steady inventory is higher (N\ :sub:`O(s)`
134.1 against SPARTA's 117.3 for gsps1): SPARTA's counter uses rates
frozen at the window start, i.e. explicit Euler for desorption
(:math:`k_{DS}\Delta t` = 0.210), whose post-step inventory is
:math:`a(1 - x)/x` against the exact :math:`a\,e^{-x}/(1 - e^{-x})`;
the ratio 1.137 is measured as 1.144. LH2 (0.14 % of the impacts)
follows this inventory and differs by 13 % (0.874 :math:`\pm` 0.026).
With ``nsync 10`` SPARTA executes, from frozen counts, 1.57 DS events
per impact against 0.75 adsorptions and so creates 0.91 O atom per
impact; ours skips the infeasible events (no atom creation).

The error converges linearly in ``psSubStepTolerance`` and does not
depend on the stiffness; the sub-steps grow as
:math:`\log(2k\theta_0\Delta t)`.

The discrete integrators were checked against the exact mean field
and an independent Monte Carlo of the same algorithms (4000
replicas): ``timeCounter`` max :math:`z` 1.90 (DS) and 1.18 (LH2) against the
algorithm Monte Carlo;
``stochastic`` (exact SSA) max :math:`z` 2.47 and 1.07 against the
exact solution. SG25's Algorithm 3 as printed performs every event
one waiting time early (max :math:`z` 13.05 before the fix); the
waiting time is now drawn before the event.

Run it yourself
---------------

Three tutorials in ``tutorials/verification/gsi/`` reproduce the
decisive checks of this page (one core, under a minute each):

* ``B3_linearNetwork``: the linear PS network with a full M against
  its closed form, the O and C atom balances and the bitwise restart;
* ``B3_coverageLH2``: the legacy ``coverage_lh2`` case through the
  translation, :math:`\theta(10^{-4}\,s)` = 0.1904761917 against the
  exact 0.1904761905;
* ``B3_beamPSTwin``: the gs/ps beam twin (gsps2, ``timeCounter``)
  against the means of the 20 SPARTA seeds stored in the tutorial.

Copy a tutorial to a run directory and type ``./Allrun``; it ends with
``check.py``, which prints PASS or FAIL per metric, redraws the
comparison in ``plots/`` and finishes with ``PASS: n/n metrics pass``.
The statistical metrics allow four standard errors.
