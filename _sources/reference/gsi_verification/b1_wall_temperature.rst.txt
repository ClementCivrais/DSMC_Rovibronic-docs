B1: per-face wall temperature
=============================

**Verified:** every wall whose kernel re-emits at a wall temperature
takes it per face from one implementation in ``dsmcPatchBoundary``,
with three models (``uniform``, ``radiativeEquilibrium``,
``coupled``); the chemical heat released at the wall is kept in its
own ledger (the analogue of SPARTA's ``echem``), so the wall heat is
:math:`q_{BF} + q_{chem}`. **Against:** bitwise regression of the
uniform mode, the analytic radiative-equilibrium root, the analytic
fixed point of a catalytic radiative-equilibrium face, and a SPARTA
``fix surf/temp`` twin on a cylinder.

Regression of the uniform mode (R1)
-----------------------------------

Each case was run with the baseline and the B1 binaries and the same
``randomSeed``; every file of every common write time was compared
byte for byte. ``couette_cll``, ``accom_rot``, ``radeq_Ar`` and the
catalytic case are identical (the catalytic chemical ledger equals
the wall's own cumulative recombination energy to 7e-15). On the two
walls that inject parcels, the wall fluxes now subtract the energy
the injected parcels carry away:

Catalysis on a radiative-equilibrium face (V3)
----------------------------------------------

A free-molecular O stream (10\ :sup:`19` m\ :sup:`-3`, 300 K,
2 km/s) strikes a catalytic radiative-equilibrium face
(:math:`\varepsilon` = 0.002), :math:`\gamma(T_w) = e^{-3000/T_w}`,
:math:`E_{rec}` = 8.203e-19 J. The oracle is the face balance

.. math::

   \varepsilon\sigma(T_w^4 - T_{bg}^4) = q_{in}
     - (1 - \gamma)\Gamma(2kT_w + \langle e_O\rangle)
     - \tfrac{\gamma\Gamma}{2}(2kT_w + \langle e_{O_2}\rangle)
     + \tfrac{\gamma\Gamma}{2}\,\beta_{acc} E_{rec}.

Restart (V4) and the conjugate solid (V5)
-----------------------------------------

Ten steps after a restart that falls inside an update interval (the
next update still 14 steps away), the face temperature
(1599.60860368346 K), the relaxed flux and the ledger times are
bit-identical to the restart file; without the file the wall
falls back to the dictionary's 300 K. The ``dsmcFoamAblation`` melt
case (O at 4 km/s onto aluminium) gives identical gas (356 files),
solid (28 files) and log (328/328 lines) with the baseline and the
B1 build: the coupled face temperature (300 → 474.6 K) now enters
through the ``coupled`` model. An asymmetric two-processor restart
of the coverage, ablating and wall-temperature files returns each
processor its own state (for example :math:`\theta` =
0.041594709305446 and 0.043017825104560).

Cost
----

On a channel dominated by wall impacts (1.25e4 impacts per step) the
uniform mode costs 1.0020 times the baseline instructions per step
(about 38 instructions per impact) and 1.0040 in wall time. The
non-per-impact code lives in a separate source file
(``dsmcPatchBoundaryWallTemperature.C``) so that the compiler keeps
the hot wall functions inlined.

Reproduce
---------

``run/GSI/B1_wallTemperature/`` (one directory per test:
``R1_regression``, ``V2_radeq``, ``V3_catalysis``, ``V4_restart``,
``V5_conjugate``, ``cylinder_twin``, ``perf``, ``Review_fixes``);
figures by ``run/GSI/B1_wallTemperature/plot_b1.py``. Note:
``docs/Development/Verification/gsi/b1_wall_temperature.md``.

Run it yourself
---------------

Two tutorials in ``tutorials/verification/gsi/`` reproduce the
analytic checks of this page (one core):

* ``B1_radEqPlate``: Ar plate on a diffuse wall with
  ``wallTemperatureModel radiativeEquilibrium`` against the analytic
  root 1599.69 K (V2, about 6 minutes);
* ``B1_catalyticRadEq``: catalytic radiative-equilibrium face,
  :math:`\beta_{acc}` = 1, against the oracle root 2069.03 K and
  :math:`\gamma = e^{-3000/\langle T_w\rangle}` (V3, about 1.5
  minutes).

Copy a tutorial to a run directory and type ``./Allrun``; it ends with
``check.py``, which prints PASS or FAIL per metric, redraws the
comparison in ``plots/`` and finishes with ``PASS: n/n metrics pass``.
The tolerances are stated in each README (statistical where the
result is).
